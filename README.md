WebTrack

WebTrack is a small web app for tracking a batch of computers through a rollout. Each device moves through stages (imaged, installed, tested, handed over), and you can filter by site and export a summary report as CSV.
I built it after doing a 20-machine store computer upgrade at work, where I wanted a cleaner way to see what was done and what was still left.

Stack: Python, SQLite, JavaScript, HTML/CSS3
